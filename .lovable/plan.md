
# agentic.engineer — Conference Landing Page

## Design
Dark terminal/hacker aesthetic with black background, monospace fonts, cyan/green accents. ASCII art used heavily for decoration and section headers. Code-comment style labels (e.g., `// SPEAKERS`, `$ ./register`). Subtle scan-line or CRT effects via CSS.

## Sections (top to bottom)

### 1. Navigation Bar
- ASCII-styled logo: `[agentic.engineer]`
- Monospace nav links: Speakers, Schedule (coming soon), Sponsors (coming soon)
- Blinking cursor element

### 2. Hero Section
- Large ASCII art banner spelling out "AGENTIC" or conference branding
- Tagline: "The conference for engineers building autonomous AI agents"
- Animated terminal-style typing effect for the tagline
- "WAITLIST" button styled as a terminal command prompt `$ ./join-waitlist`
- Date/location shown as TBD with placeholder: `DATE: TBD | LOCATION: TBD`

### 3. Live Countdown Timer
- Label: `● LIVE_COUNTDOWN` with blinking dot
- Flip-clock style boxes for Days, Hours, Minutes, Seconds (placeholder target date)
- Styled with dark cards and monospace numbers
- Waitlist CTA repeated below

### 4. Conference Stats (// CONFERENCE_SPECS)
- Grid of stats with colored accent borders (cyan, green, yellow)
- Numbers like: Speakers, Sessions, Tracks, Workshops, Days, Engineers
- Left-border colored bars for each stat, monospace numbers

### 5. ASCII Art City Skyline Divider
- A decorative ASCII art section made of binary/code characters

### 6. Speakers Section
- Header: `[Speakers]` with bracket styling
- Subtitle: `// more speakers announcing soon`
- Grid of placeholder speaker cards with terminal-styled borders
- Each card: Name, Title, Company — styled like a terminal output table
- Placeholder data for ~8 sample speakers

### 7. Email Signup
- Header: `SUBSCRIBE FOR UPDATES`
- Email input + "Sign up" button styled as terminal input
- Monospace placeholder text

### 8. Footer
- ASCII art divider
- Links styled as terminal commands
- `© 2026 agentic.engineer` in monospace

## Key Visual Effects
- Blinking cursor animations
- Subtle text-shadow glow on accent colors
- Scan-line CSS overlay for CRT feel
- ASCII art decorations between sections
